This project automates the collection and organization of Max Pain data across multiple equities. It scans through equity-specific folders containing monthly option chain analyses, extracts expiry-wise Max Pain levels from summary CSV files, and consolidates them into clean, structured reports. For each expiry date, the script generates a CSV file listing all equities with their corresponding Max Pain values, making it easy to compare option pain points across the market. The solution includes error handling for missing or malformed files, ensures directory structure compliance, and produces neatly organized output for further analysis or visualization.
